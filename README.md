# 📧 Email Extractor — Python Automation

A simple Python automation project that extracts email addresses from a text file and saves them into a separate output file.

This project was developed as part of the **CodeAlpha Python Programming Internship — Task 3: Task Automation with Python Scripts**.

---

## 📌 Project Overview

The Email Extractor reads a text file containing contact information, identifies valid email addresses using Python's **Regular Expression (`re`) module**, removes duplicate addresses, and saves the extracted emails into a separate file.

### Workflow

```text
Contact Data
     ↓
Read Text File
     ↓
Find Email Addresses
     ↓
Remove Duplicates
     ↓
Save Extracted Emails
